🗂️ Kanban Task Board (React + Tailwind + Drag & Drop)
A simple and clean Kanban-style task management board built with React, Tailwind CSS, and @hello-pangea/dnd for drag-and-drop functionality. The app allows users to:

Add, edit, delete tasks

Assign tasks with avatars and assignees

Drag tasks between columns

View assignee badges and timestamps

Use a modal form to manage tasks

📦 Features
React + TypeScript based architecture

Tailwind CSS for fast and responsive styling

Drag and drop support using @hello-pangea/dnd

Task modal with form validation

Avatar/image selector

Live task management UI

Lightweight local state (Zustand-like store)
